DevCleaner is a Windows desktop app (Flutter GUI + Rust backend) that scans your machine for stale package caches and build artifacts — NuGet, Cargo, Go modules, npm, pip, Maven, Gradle, vcpkg, Conan, IDE caches, browser caches, temp files, and more. It shows you exactly what it found and how much space each item takes before you decide what to delete. Download the latest installer from the [Releases page](https://github.com/NeverMorewd/DevCleaner/releases).
